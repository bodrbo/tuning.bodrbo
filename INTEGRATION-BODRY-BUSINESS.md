# Интеграция формы с «Бодрым Бизнесом»

Форма на `bodrbo-tuning.ru` отправляет заявку на локальный PHP-обработчик. Он проверяет поля, ограничивает частоту запросов и передаёт данные в «Бодрый Бизнес» по защищённому server-to-server API.

```text
браузер → bodrbo-tuning.ru/submit-request.php → business.bodrbo.ru/api/integrations/tuning-leads
браузер → bodrbo-tuning.ru/boat-catalog-search.php → business.bodrbo.ru/api/integrations/tuning-boat-catalog
```

Секрет API никогда не передаётся браузеру и не хранится в Git.

## 1. Создать общий секрет

В SSH-терминале Beget выполните:

```bash
openssl rand -hex 32
```

Сохраните результат в менеджере паролей. Один и тот же секрет нужно добавить в обе серверные конфигурации ниже.

## 2. Настроить «Бодрый Бизнес»

В файле `.env`, который загружает Passenger приложения `business.bodrbo.ru`, добавьте:

```dotenv
TUNING_SITE_WEBHOOK_SECRET=ВСТАВЬТЕ_СЕКРЕТ
```

Файл `.env` находится рядом с рабочим `passenger_wsgi.py` и не должен попадать в Git. После изменения перезапустите приложение через панель Beget или Passenger.

## 3. Настроить сайт тюнинг-центра

После обновления репозитория сайта создайте конфигурацию за пределами `public_html`:

```bash
cd ~/tuning.bodrbo.ru
cp public_html/integration-config.example.php integration-config.php
chmod 600 integration-config.php
nano integration-config.php
```

Укажите тот же секрет:

```php
<?php
return [
    'endpoint' => 'https://business.bodrbo.ru/api/integrations/tuning-leads',
    'catalog_endpoint' => 'https://business.bodrbo.ru/api/integrations/tuning-boat-catalog',
    'secret' => 'ВСТАВЬТЕ_СЕКРЕТ',
];
```

Итоговый путь должен быть таким:

```text
~/tuning.bodrbo.ru/integration-config.php
```

Не переносите этот файл в `public_html` и не добавляйте его в Git.

## 4. Проверить

1. Откройте форму на `https://bodrbo-tuning.ru/`.
2. Отправьте тестовую заявку с узнаваемым именем.
3. Убедитесь, что форма показала сообщение об успешной отправке.
4. Откройте «Бодрый Бизнес» → **Тюнинг-центр → Заказы**.
5. Должен появиться заказ со статусом **Новая заявка** и источником `tuning_site`.
6. Повторная доставка с тем же `request_id` не должна создавать дубликат.

## Что сохраняется в заказе

- имя и телефон клиента;
- модель катера, если указана;
- идентификатор выбранной модели каталога: система перепроверяет его и сохраняет каноническое название;
- описание задачи;
- адрес страницы, с которой отправлена форма;
- время отправки;
- уникальный идентификатор для защиты от дублей.

Для каждой заявки корпоративная система также создаёт связанный финансовый проект.

## Фотография в заявке

Все рабочие формы сайта, включая боковую форму обратного звонка и заявку на хранение,
принимают одну фотографию JPG, PNG или WebP до 5 МБ. До отправки доступны превью и удаление.
PHP должен разрешать `upload_max_filesize` не менее `5M` и `post_max_size` не менее `8M`.

Сайт проверяет загрузку и содержимое изображения, затем добавляет к JSON заявки поле
`photo` с `filename`, `content_type` и `data` (Base64). Файл передаётся через тот же
авторизованный server-to-server API. В «Бодром Бизнесе» он сохраняется в закрытой
папке `private_tuning_request_photos` рядом с базой данных и отображается в карточке
заказа. Папку следует включать в резервное копирование вместе с базой.

При сохранении фотографии API возвращает `photo_received: true`. Сайт подтверждает
успех только после получения этого признака. Повторная отправка с тем же
`request_id` сохраняет один заказ и одну фотографию. Если заказ уже был создан без
фотографии, повторный запрос может добавить её к этому заказу.

Сначала обновите «Бодрый Бизнес», затем сайт. Схема таблицы вложений создаётся при
обычной инициализации базы приложения. Заявки без фотографии сохраняют прежний формат.

## Диагностика

- `422` — посетитель ввёл некорректные данные;
- `429` — превышено пять попыток за десять минут с одного IP;
- `502` — корпоративная система не ответила или вернула ошибку;
- `503` — отсутствует `integration-config.php`, секрет или PHP cURL.

Поиск моделей начинает работать с двух символов, поддерживает русское фонетическое написание (например, «Байэланер» → `Bayliner`) и не передаёт секрет интеграции в браузер. Если каталог временно недоступен или нужной модели ещё нет, посетитель по-прежнему может ввести название вручную.

Серверные ошибки записываются без имени, телефона и текста заявки. В журнал попадают только технический статус и `request_id`.

## Справочник лодок

Публичный раздел /spravochnik/ использует отдельный снимок каталога. Сайт
открывает карточки и ищет модели по снимку, даже если «Бодрый Бизнес» временно
недоступен. API автодополнения для формы заявки работает независимо.

Для импорта нужен полный JSON-экспорт моделей. Сохраните только данные моделей,
предназначенные для публикации, и скопируйте одобренные фотографии в assets/boat-guide/.
Экспорт может быть массивом записей или объектом с массивом items:

```json
{
  "items": [
    {
      "id": 123,
      "model_name": "585 НТ",
      "brand": "Салют",
      "profile_slug": "salyut-585-nt",
      "aliases": ["Салют 585 HT", "Салют 585НТ"],
      "facts": {"Длина корпуса": "5,85 м"},
      "photos": ["/assets/boat-guide/salyut-585-nt/side.jpg"]
    }
  ]
}
```

Поля id и model_name обязательны. Вместо model_name принимается name.
profile_slug привязывает запись к уже созданной редакционной странице, если
названия различаются. Для прочих моделей URL формируется по стабильному ID.
Снимок заменяется целиком после проверки выгрузки. Перед первым импортом
проверьте соответствие названий и модификаций, затем выполните из public_html:

```sh
php content/import-boat-guide.php /путь/к/выгрузке.json
```

Редакционные тексты, уточнённые характеристики, открытые источники и связи с
кейсами хранятся в content/boat-guide.json отдельно от импорта. В поля cases
передаются slug опубликованных проектов. Редакционная карточка сохраняет свой
адрес при повторном импорте. При дополнении уже импортированной модели
используйте её текущий slug, например model-123. В карту сайта попадают страницы с редакционным
описанием и характеристиками или источниками. Остальные карточки доступны в
обычном поиске по справочнику.
