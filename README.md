# tuning.bodrbo.ru

Сайт тюнинг-центра «Бодрый Боцман»: услуги по ремонту и модернизации катеров, архив проектов и подробные статьи о выполненных работах.

## Локальный запуск

Сайт статический. Для просмотра достаточно запустить локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

После этого сайт будет доступен по адресу <http://127.0.0.1:4173/>.

## Структура

- `index.html` — главная страница;
- `projects.html` — архив проектов;
- `project.html` — шаблон подробного кейса;
- `projects-data.js` — данные опубликованных кейсов;
- `assets/` — изображения и фотографии проектов;
- `styles.css` и `script.js` — оформление и клиентская логика;
- `submit-request.php` — серверная отправка заявок в «Бодрый Бизнес»;
- `INTEGRATION-BODRY-BUSINESS.md` — настройка интеграции формы;
- `DEPLOY-BEGET.md` — инструкция по первой публикации на Beget;
- `GIT-BEGET.md` — подключение GitHub к Beget и обновление сайта через SSH.

## Production-сборка

```bash
./build-release.sh
```

Готовые папка и ZIP-архив создаются в `release/`. Этот каталог не добавляется в Git.
