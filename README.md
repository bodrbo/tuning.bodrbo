# tuning.bodrbo.ru

Сайт тюнинг-центра «Бодрый Боцман»: услуги по ремонту и модернизации катеров, каталог лодочных моторов Marine Rocket, архив проектов и подробные статьи о выполненных работах.

## Локальный запуск

Интерфейс сайта статический, а форма и онлайн-каталог используют небольшие PHP-обработчики. Для полноценного локального просмотра запустите сервер из корня проекта:

```bash
php -S 127.0.0.1:4173
```

После этого сайт будет доступен по адресу <http://127.0.0.1:4173/>.

Для каталога необходимы PHP-расширения cURL и SimpleXML и доступ к YML-фиду Marine Rocket.

## Структура

- `index.html` — главная страница;
- `projects.html` — архив проектов;
- `project.html` — шаблон подробного кейса;
- `motors.html` — каталог лодочных моторов Marine Rocket;
- `motor.php` — серверный шаблон страницы отдельного мотора;
- `motors.js` и `motor-page.js` — каталог, карточки, галерея и отправка ссылки на мотор;
- `marine-rocket-catalog.php` — безопасная загрузка, SEO-slug и кеширование YML-каталога поставщика;
- `motor-sitemap.php` — динамическая карта страниц моторов;
- `projects-data.js` — данные опубликованных кейсов;
- `assets/` — изображения и фотографии проектов;
- `styles.css` и `script.js` — оформление и клиентская логика;
- `submit-request.php` — серверная отправка заявок в «Бодрый Бизнес»;
- `INTEGRATION-BODRY-BUSINESS.md` — настройка интеграции формы;
- `DEPLOY-BEGET.md` — инструкция по первой публикации на Beget;
- `GIT-BEGET.md` — подключение GitHub к Beget и обновление сайта через SSH.

## Production-сборка

```bash
./build-release.sh
```

Готовые папка и ZIP-архив создаются в `release/`. Этот каталог не добавляется в Git.

Production-адрес: <https://tuning.bodrbo.ru/>.

Каталог моторов обновляется с YML-фида поставщика раз в 30 минут. Для каждой модели автоматически создаётся страница с постоянным адресом, серверными метатегами и микроразметкой Product. В публичный JSON попадают только моторы, цены, изображения и характеристики; дилерские цены и складская детализация не публикуются. Если поставщик временно недоступен, обработчик показывает последнюю сохранённую копию.
